# 올리브교회 홈페이지

파일을 압축 해제한 뒤 `index.html`을 더블클릭하면 바로 확인할 수 있습니다.

## 포함 내용
- 올리브교회 사용자 제공 로고 적용
- 대한예수교장로회 교단 로고 적용
- '모두[All]가 살고, 모두[all]를 살리는 교회!' 메인 메시지
- 올리브나무와 열매 SVG 일러스트
- 교회소개 / 예배안내 / 올리브 이야기 / 담임목사 / 오시는 길 / 문의
- PC·태블릿·스마트폰 반응형
- 네이버지도·카카오맵 연결 버튼

## 수정이 필요한 항목
`index.html`에서 주일예배 시간, 주중예배 시간, 전화번호, 이메일, 목사님 인사말/약력 등을 실제 정보로 교체하면 됩니다.

- 메인 오른쪽에 실제감 있는 올리브나무와 열매 이미지를 적용했습니다.
